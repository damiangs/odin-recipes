# Project Recipes 🍽️

A simple recipe website built as my first project in [The Odin Project](https://www.theodinproject.com/). It’s a small, hands-on way to put the first HTML lessons into practice by bringing a few recipes together in one place.

## About

This project focuses on the foundations of HTML—not styling or JavaScript. The pages use semantic structure and basic elements to present recipe information clearly, including headings, paragraphs, links, images, and ingredient and instruction lists.

## What I’m practicing

- Creating a basic HTML document
- Organizing content with headings and paragraphs
- Linking pages together
- Adding images with descriptive alternative text
- Presenting ingredients and steps with lists

## Run it locally

No setup or dependencies are needed. Clone or download the project, then open `index.html` in a web browser.

## Next steps

This is an early learning project, so the focus is on getting the HTML right. CSS and other enhancements can come later, after the fundamentals have had their turn in the kitchen.
